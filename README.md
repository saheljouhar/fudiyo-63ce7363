# Fudiyo
Restaurant ordering and waiter management system for Kerala restaurants.

## What it does
- Waiters manage table orders through a mobile interface
- Kitchen receives orders instantly
- Reduces errors and speeds up service

## Problem it solves
Most Kerala restaurants still use paper-based ordering.
Fudiyo digitises the process with zero customer app required.
FUDIYO POS IS PART OF AN PROJECT [FUDIYO],expected to release when 2027

## Tech stack
- React + TanStack (frontend)
- Supabase (backend and database)
